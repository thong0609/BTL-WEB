# Frontend tooling — step 1

Next.js/TypeScript dependencies, lockfile, ESLint and TypeScript configuration only.
App Router pages/layout, providers and API client are scheduled for setup step 5.

From this directory: `npm ci`, `npm run lint`, `npm run typecheck`.
The `dev`, `build` and `start` commands are configured for the later application;
they are not ready until an App Router page and root layout exist.
